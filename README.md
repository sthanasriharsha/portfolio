## 🚀 Featured Projects (Showcased in Portfolio)

### 🌃 Low Light Image Enhancement
> Python-based system to improve nighttime roadside images for intelligent transportation using bidirectional area segmentation-based inverse tone mapping. Deployed as a Flask web app.
- **Stack:** Python · OpenCV · Flask · NumPy
- **[Live Demo](https://low-light-image-enhancement-m2yb.onrender.com/)** | **[GitHub](https://github.com/sthanasriharsha/LOW_LIGHT_IMAGE_ENHANCEMENT)**

### 🤖 AI Document Assistant
> Web-based assistant for intelligent PDF/DOCX analysis — supports contextual Q&A, summarization, and multi-turn conversation powered by Google Gemini.
- **Stack:** Python · Streamlit · OpenAI GPT-4 · NLP
- **[Live Demo](https://ai-doc-assistant-hyx46c3ivdxb5zzgs3ztmt.streamlit.app/)** | **[GitHub](https://github.com/sthanasriharsha/ai-doc-assistant)**

### 📐 Pose Normalization Pipeline
> Standardizes human body keypoints extracted from video using DWPose, improving consistency for Sign Language AI across different scales and viewpoints.
- **Stack:** PyTorch · Python · Computer Vision · Pose Estimation
- **[Live Demo](https://huggingface.co/spaces/Harsha909/pose-normalization-v3)** | **[GitHub](https://github.com/sthanasriharsha/pose-normalization)**

### 🌐 Word Sense Disambiguation
> NLP system that detects ambiguous words in text and determines their correct contextual meaning using ConSeC model with relevance scoring.
- **Stack:** Python · SpaCy · WordNet · PyTorch · Hugging Face
- **[Live Demo](https://huggingface.co/spaces/Harsha909/wsd-scorer)** | **[GitHub](https://github.com/sthanasriharsha/wsd)**
